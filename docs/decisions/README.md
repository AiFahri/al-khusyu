# Architecture Decisions

Architecture decision records preserve the context and tradeoffs behind stable
technical choices.

| Record | Status | Decision |
| --- | --- | --- |
| [ADR-0001](0001-client-rendered-frontend.md) | Accepted | Use a client-rendered React frontend |
| [ADR-0002](0002-typed-local-content.md) | Accepted | Keep current editorial collections typed and local |

New records should describe the context, decision, consequences, and realistic
alternatives. Accepted records are not edited to hide later changes; supersede
them with a new record that links back to the earlier decision.
