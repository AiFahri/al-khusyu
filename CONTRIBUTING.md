# Contributing To AlKhusyu

Thank you for improving the public Al-Khusyu' institutional frontend.

## Before You Begin

- Keep each change focused on one problem.
- Confirm institutional facts and media rights with the responsible maintainer.
- Do not commit credentials, student records, private contact data, or internal
  operational documents.
- Preserve the established React, TypeScript, Tailwind CSS, and route patterns.

## Development Workflow

1. Create a branch from the current `main` branch.
2. Install the locked dependency tree with `npm ci`.
3. Make the smallest complete change that solves the problem.
4. Run `npm run lint`, `npm run typecheck`, and `npm run build`.
5. Open a pull request with context, verification notes, and relevant visuals.

## Commit Style

Use concise conventional prefixes such as `feat`, `fix`, `docs`, `refactor`,
`test`, `chore`, and `ci`. Write the subject as an imperative description of
the outcome, for example `fix(navigation): preserve education deep links`.

## Content Changes

Content contributions must include an attributable source or confirmation from
the responsible education unit. Images need meaningful alternative text,
appropriate compression, and permission for public use.
